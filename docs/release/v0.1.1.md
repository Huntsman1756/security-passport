# v0.1.1 — reuse-first hardening

Second-pass release: less custom code, better-integrated
evidence, hard gates. Every release claim is verifiable offline
from the fixture corpus.

## What changed

| Change | Detail |
|---|---|
| Artifact store | `evidence/store.py` — content-addressed SHA-256 blobs, write-once, append-only `artifacts.jsonl` + `attempts.jsonl`. Pattern ported from `OpenInstrument/artifacts/store.py` + `posttrade-europe/capture` (attempts-as-data incl. failures). |
| ISIN validation | `domain/isin.py` now wraps `python-stdnum` (ISO 6166 + ISO 17442 LEI). Custom Luhn deleted; kept as test oracle in `tests/unit/test_isin_stdnum.py`. |
| Upstream fix | OpenInstrument `/v1/evidence` hardcoded-snapshot bug fixed upstream (`openinstrument@50e9677`), regression-tested, pinned via `MIN_OPENINSTRUMENT_COMMIT`. |
| ECB dictionary | New source: `providers/ecb_dictionary.py` parses the official codebook → `stores/collateral_dictionary.json`. Fixed the mislabelled `CLBL01` (joint Euroclear Bank/Clearstream ICSD, not CBL Lux alone). |
| Instrument-level CSD | New adapter `providers/euronext_esmil.py` parses the "ISINs eligible for settlement in ESM" workbook → `post_trade.csd_admission` + `instrument_csd_evidence` collection. |
| Golden corpus | 8 → 31 cases covering equity/debt/fund/ETF/sovereigns/delisted/sentinel/conflict/absence edges — `docs/golden-coverage.md`. |
| Differential suite | `services/differential.py` + verdict taxonomy (SAME / EXPECTED_TRANSFORMATION / SOURCE_VERSION_SKEW / SEMANTIC_DIFFERENCE / BUG / UNEXPLAINED). |
| API hardening | Schemathesis property tests (5 endpoint groups, ~300 cases); `oasdiff breaking` gate in CI against `tests/fixtures/openapi-baseline.json`. |

## Code removed by reuse

- `domain/isin.py` custom Luhn (retired to test oracle).
- `evidence.archive_raw` path-based layout → `ArtifactStore`.
- `iberclear.SSS_BY_CSD_CODE` hand guesses → ECB dictionary
  (the table remains as a verbatim fallback).

## Remaining duplications (justified)

| Duplication | Why kept |
|---|---|
| SP ECB eligible-assets ingest vs OI `ecb_ea` adapter | SP needs snapshot-scoped absence semantics + haircut decimals; OI is corroborating, differential-tested |
| `issuance_date`/`maturity` in SP store vs OI debt attrs | SP exposes them as field-level evidence w/ rule refs; same source, different grain |
| `SSS_BY_CSD_CODE` fallback table | verbatim copy of the ECB dictionary for offline rebuilds — labelled as fallback, not authority |
