# v0.2.0 — Temporal passport

`--as-of` / `?as_of=` makes the passport answer **only what
admissible evidence could support at T** — evidence is selected
at T first, then deterministic rules re-run on those inputs. The
current passport is never built and truncated.

## Three orthogonal epistemology axes (now explicit)

| axis | values | axis of |
|---|---|---|
| `FieldStatus` | reported / derived / inferred / not_found / not_applicable / conflict | what the value *is* |
| `AssessmentVerdict` | topology_only / not_assessable / … | evaluation result |
| `TemporalAnswerState` | available / partial / outside_coverage / unavailable | what T supports |
| `TemporalBasis` | native_history / reconstructed / observed_history / current_only | how coverage is derived |

## Per-block admissibility at T

- **identity / secondary_market** (`reconstructed`, FIRDS via
  OpenInstrument): admissible iff provider-dated evidence exists
  at T; listing state recomputed at T (`terminated` only if
  `termination_date ≤ T`); pre-evidence T → `outside_coverage`.
- **primary_market** (`observed_history`, our PRIII captures):
  admissible iff T ≥ first observation; earlier T →
  `outside_coverage` + "Current data has NOT been substituted."
- **eurosystem_collateral** (`current_only`, single snapshot):
  admissible iff T ≥ snapshot publication; earlier T →
  `outside_coverage` — never projected backwards.
- **post_trade** (`observed_history`): settlement locations
  admissible iff `source_published_at ≤ T`; a location carries
  `effective` iff `effective_from ≤ T` — knowledge ≠
  effectiveness. SSS topology excluded when its page stamp
  postdates T.

## Hard gate

`check_passport` now fails if any `outside_coverage` /
`unavailable` block carries a positive field — substitution of
current values into historical windows is a release defect.

## Demo

```
security-passport IE00B4L5Y983 --as-of 2026-09-19
  → Milan file known (published 09-18), designated place NOT
    yet effective (effective_from 09-21)
security-passport IE00B4L5Y983 --as-of 2026-09-21
  → same locations, now `effective: true`
security-passport IE00B4L5Y983 --as-of 2020-01-01
  → primary/post-trade/collateral all `outside_coverage`,
    no current data substituted
```

## OpenVenue rulebook layer (minimal)

`OPENVENUE_URL` (or `corpus/venues/{MIC}.json`) adds
`rulebook_family` + `rulebook_state` + `rulebooks[]`
(title/document_id/effective_from/sha256/captured_at) per
listing. `NOT_IN_CORPUS` is reported honestly. No dossier
import, no article-level applicability inference.
